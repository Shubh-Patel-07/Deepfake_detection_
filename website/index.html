Understanding the Threat

What is a Deepfake?

Deepfakes are highly realistic, AI-generated synthetic media where a person in an existing image or video is replaced with someone else's likeness. Using advanced neural networks, malicious actors can create videos of people saying or doing things they never did.

Our solution approaches this challenge by recognizing that manipulation introduces subtle spatial anomalies as well as temporal inconsistencies across multiple frames.

Our Advanced Hybrid Solution

This project utilizes a state-of-the-art ResNext50 + LSTM Hybrid architecture. The CNN backbone extracts deep spatial features per frame, while the LSTM models temporal sequence modeling across frames.

Trained on a massive combined dataset of 23,186 videos from DFDC, Celeb-DF v2, and FaceForensics++, our system achieves a rigorously validated 87% classification accuracy.

How It Works: Spatio-Temporal Pipeline

1. Frame Extraction & Filtering

User uploads a video file. Videos with <100 frames or audio-only manipulations are filtered out. OpenCV dynamically extracts exactly 20 frames for inference sequence analysis.

2. Face Detection

The dlib-based face_recognition library scans extracted frames to accurately locate human faces. (Client-side previews use face-api.js).

3. Spatial Feature Extraction

Faces are cropped to 112×112 and passed into the PyTorch ResNext50 backbone, running through an AdaptiveAvgPool2d to generate a precise 2048-dimensional feature vector per frame.

4. Temporal Modeling (LSTM)

The extracted sequences of 2048-dim vectors are fed into an LSTM (Long Short-Term Memory) network. It evaluates how features change over time to detect temporal jitter and blending flaws.

5. Classification & Explainability

The LSTM's final hidden state passes through a Linear(2048, 2) layer yielding a Softmax 2-Class prediction (Real=1, Fake=0). CAM Heatmaps (JET colormap) are generated to highlight manipulated regions.

Machine Learning Details

Model Architecture: ResNext50 + LSTM

Our hybrid network is optimized for spatio-temporal dynamics. The spatial backbone is initialized with ImageNet weights, extracting 2048-d features. These are passed sequentially to an LSTM.

The network leverages LeakyReLU activation, a Dropout rate of 0.4, and finishes with a 2-class linear output: nn.Linear(2048, 2).

Dataset & Strategy

Trained dynamically across three major sets: DFDC, Celeb-DF v2, and FaceForensics++ yielding 23,186 total videos. Data is rigorously balanced. Training relied on 10-frame sequences with random temporal jitter for superior generalization.

Validated Model Results

🏆 87% Final Model Accuracy

Through comprehensive evaluation using scikit-learn metrics, confusion matrices, and Seaborn heatmaps, the final checkpoint (model_87_acc_20_frames_final_data.pt) demonstrates robust resilience against deepfake variations.

Inference Output Format

  • Classification: 2-Class Network (Class 1 = REAL, Class 0 = FAKE)
  • Confidence: Softmax Probability Estimation (%)
  • Explainability: Class Activation Mapping (CAM) overlays generating a JET colormap directly onto detected facial landmarks.
