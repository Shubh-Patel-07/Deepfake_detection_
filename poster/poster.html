1. INTRODUCTION

Deepfakes are AI-generated synthetic media where a person's face in a video is replaced with someone else's likeness using deep learning. This project implements an automated deepfake detection system using a hybrid ResNext50 + LSTM architecture that combines spatial and temporal analysis to classify videos as REAL or FAKE with 87% accuracy.

2. OBJECTIVE

  • Develop AI-powered deepfake video detection
  • Implement hybrid CNN+LSTM architecture
  • Leverage transfer learning from ImageNet
  • Build web-accessible detection interface
  • Provide confidence-based predictions with explainability
  • Train on diverse multi-dataset benchmark

3. PROBLEM STATEMENT

  • Deepfakes becoming visually indistinguishable from real videos
  • Manual verification is unreliable and time-consuming
  • Single-frame analysis misses temporal inconsistencies
  • Lack of accessible tools for non-experts
  • Misinformation spreads rapidly on social media

4. WHAT IS A DEEPFAKE?

A deepfake is synthetic media manipulated using advanced AI techniques to create convincing but fabricated content.

6. AI DETECTION WORKFLOW

  1. Video ingested via web interface
  2. Extract continuous frame sequence
  3. Detect and crop faces
  4. Normalize and resize to 112x112
  5. Extract spatial features (ResNext50)
  6. Analyze temporal changes (LSTM)
  7. Compute probability scores
  8. Display prediction and confidence
